版本说明

这是一个以阅读为中心的个人网站。它会继续变化；这一页记录变化所依据的选择。

字体与视觉

中文使用开源的霞鹜文楷，拉丁字符使用 Ysabeau Office，代码使用 Maple Mono CN。暖纸色、深靛蓝与朱红构成全站骨架；酒馆来信增加琥珀与夜色。字体由站点自托管，不在访问时向字体供应商发送请求。

AI 使用

AI 可以协助封面构思、编辑校对、资料整理与代码实现，但不冒充亲历、来源或作者判断。正文中的观点与最终发布责任仍由作者承担；AI 生成的视觉资产会避免复刻版权不明的原作。

评论

长篇内容预留 giscus 评论。启用后评论托管在 GitHub Discussions，需要 GitHub 登录；服务不可达不会影响正文阅读。当前未配置评论仓库时，不加载损坏的评论框。

订阅

全站内容可通过 RSS 订阅。酒馆来信另使用 Quaily 的官方订阅组件；它只出现在栏目页和每期末尾，提交与验证码由 Quaily 处理。

统计与隐私

正式主域计划使用 Cloudflare Web Analytics 查看聚合的访问量、来源页和常读内容，不设置站内 Cookie，也不记录自定义事件。Quaily 与 giscus 是读者主动使用时接触的第三方；灾备镜像与平台测试地址不纳入统计。

技术与可访问性

网站由 Astro 生成静态 HTML，Pagefind 提供本地搜索索引，主要部署于 Cloudflare Workers Static Assets，并保留无索引的 GitHub Pages 灾备镜像。核心内容与链接不依赖 JavaScript；交互支持键盘、减弱动效、明暗主题与打印样式。

本说明更新于 2026 年 8 月。
